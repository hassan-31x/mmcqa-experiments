# Experiment A: fine-tune the quantized Qwen3.5-9B

**Question.** Zero-shot, the 9B (NF4) beat the 4B by only +0.006 F1. Does fine-tuning it with the 4B's recipe give a better ceiling than the fine-tuned 4B?

**Design.** Same recipe as the 4B (QLoRA r16/alpha32, lr 1e-4 = S1 and 2e-4 = S2, batch 16, answer-token loss, same prompt, 448^2 pixel cap, NF4), same data (the 40,000 train rows), capped at the 4B's 870 optimizer steps = 13,920 examples. Training is time-budgeted (Kaggle 12 h), so if the 9B is slower per step it sees a smaller fraction of that data; the actual steps are in `logs/sft_*_sizing.json` and the report. Evaluation: first 100 dev items per track (400 items), identical to every earlier comparison.
